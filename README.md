1. Скачиваем проект кидаем куда угодно
2. Проверяем установлен ли node.js и менеджер проектов в терминале VS code (ctrl+`) 
    # node -v **Проверка node**
    # npm -v **Проверка менеджера**
3. Переходим к своей папке проекта `cd путь/к/папке/проекта`
4. Запускаем проект **Терминал 1** `npm run dev`
5. Запустить сервер **Терминал 2** `npx json-server mock/flights.json --port 4000`
